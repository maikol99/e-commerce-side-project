✨ **Backend de la tienda online con Node.js, Express, TypeScript y MongoDB.**

---

## 🚀 **Características**

- 🔑 Registro, login y verificación de usuarios  
- 🛍 Gestión de productos, categorías y stock  
- 📦 Gestión de pedidos y carrito de compras  
- 🔗 Integración con frontend  
- ⚠️ Validación y manejo de errores centralizado

---

## 🛠 **Tecnologías**

- **Node.js**  
- **Express.js**  
- **TypeScript**  
- **MongoDB** + **Mongoose**  
- **Nodemailer** (para emails de verificación)
